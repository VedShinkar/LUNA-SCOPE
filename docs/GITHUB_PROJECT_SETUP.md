# GitHub Projects Board Setup

1. Create a new GitHub Project using the Board layout.
2. Name it `LUNA-SCOPE — Engineering Development Board`.
3. Link the project to this repository from the repository's Projects tab.
4. Configure Status values: Backlog, Ready, In Progress, In Review, Done.
5. Add Priority (P0/P1/P2), Workstream, and Target date fields.
6. Create Issues with owners and acceptance criteria, then add them to the board.

Suggested first issues:
- Agree lunar coordinate and time conventions.
- Catalogue NASA terrain and ephemeris datasets.
- Create frontend and backend application shells.
- Define the first API contracts.
- Build a LOLA DEM metadata inspection script.
- Build a SPICE environment and kernel validation test.
