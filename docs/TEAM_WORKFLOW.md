# Team Workflow

## Roles
- Member 1: lunar terrain, DEM processing, 3D visualization, terrain analysis.
- Member 2: SPICE, celestial geometry, horizon/illumination, power/thermal/communication models.
- Member 3: application shell, mission intelligence, API integration, AI Copilot.
- Project lead: architecture coordination, integration, reviews, milestones, delivery.

## Board columns
Backlog -> Ready -> In Progress -> In Review -> Done

## Definition of Done
- Acceptance criteria met.
- Code reviewed through a pull request.
- Relevant tests pass.
- Data source, units, assumptions, and limitations documented for scientific outputs.
- No secrets or large datasets committed.
- Integrated behavior checked where applicable.

## Meeting rhythm
- Short team sync: agree on today's goal and blockers.
- Weekly technical review: demo working outputs, review interfaces, update risks.
- Record decisions in `docs/` rather than relying on chat history.
